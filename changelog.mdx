## v1.5.0 — July 2026

### New

- **Project sharing** — Share a project with people outside the usual workspace flow and find shared work under Shared with me
- **Credit top-ups** — Buy additional credits from an in-app credit store when you need more runway mid-cycle
- **Smarter connected files** — Semantic search over Google Drive / Dropbox sources so Builder finds the right docs in connected folders
- **Project environment variables** — Manage env vars for a project from app settings (including Supabase-related sync helpers)
- **QA agent** — A QA agent that can verify builds and run Playwright smoke checks before you ship
- **Onboarding templates** — Start from a template and a prefilled prompt during onboarding
- **Payment invoices** — Open invoices from Payment History in billing settings
- **More AI/ML API models** — Expanded AI/ML API roster in the model picker, with clearer BYOK labeling

### Improved

- **Upgrade when out of credits** — Clearer upgrade prompt from the projects list when you don’t have enough credits to continue
- **Docs-aware planning** — Agents consult official Builder docs before planning so guidance matches the product
- **Supabase reliability** — Self-healing when a Supabase connection needs to refresh account/project info
- **Sandbox rename UI** — Clearer handling when a sandbox is renamed
- **File chips in chat** — Larger click target to expand file content from an attachment name
- **Settings layout** — Settings modal width stays consistent across tabs

### Fixed

- **Free plan model gating** — Free-plan ledger credits no longer unlock paid models
- **AI/ML API BYOK** — Connected AI/ML API models remain selectable in the picker
- **Chat scroll** — Chat forces scroll to the latest message when you send or answer a question
- **Project switcher** — Rename field no longer overlaps the toolbar CTA
- **Publish credit styling** — Credit/publish UI styling fixes on constrained layouts

## v1.4.0 — July 2026

- **Edit and resend messages** — Copy, edit, or resend your own chat messages without starting over

### Fixed

- **AI/ML API BYOK** — Connected AI/ML API models show and select correctly in the picker again
- **External images** — PNG sources from connected external files render reliably in preview
- **Fresh-project publish** — Publishing works on newly created projects
- **Incognito preview** — Live preview loads correctly in private browsing windows
- **Chat polish** — Toolbar overflow, tip button contrast, and related mobile/chat layout issues

## v1.2.0 — June 2026

### New

- **Smarter long conversations** — Builder recalls the most relevant earlier messages and decisions, not just the latest turns
- **Cross-session memory** — Important project facts carry over when you return to a project
- **Any-stack app runtime** — Build beyond Vite/React presets; all project files are editable, including frontend env configs. Existing projects migrate automatically
- **Data connectors** — Connect Google Drive and Dropbox in workspace settings and use those files as data sources while you build
- **Faster live preview** — Preview loads sooner with less white flash while the sandbox starts
- **Image paste in chat** — Paste PNG or JPEG into the composer with ⌘V / Ctrl+V
- **Multi-file upload** — Attach several files to a message at once
- **Multiple-choice agent questions** — Tap to answer when the agent needs a decision
- **Browser completion notifications** — Optional notification when a long build or chat finishes in another tab
- **Richer generated apps** — Stronger guidance for accessibility, navigation, performance, data viz, motion, and polish
- **Smarter agent default** — Reopening an in-progress project starts on the Builder agent; new projects still begin with Product Architect

### Improved

- **Billing emails** — Receipt, payment-failed, and cancellation emails use branded templates
- **Docs-aware agents** — Builder and Product Architect can consult official docs when explaining platform capabilities
- **GitHub Sync** — Clearer message and Integrations deep-link when GitHub is not connected
- **Model availability** — Natively Max in the picker; clearer model limits for supported models
- **Attachment privacy** — Uploaded filenames are hidden on attachment chips
- **Upload errors** — Toasts show the specific failure reason
- **Dismissible toasts** — Every notification toast has a close control

### Fixed

- **Failed message retry** — Prompt text is restored if a send fails
- **Auto-fix and Ask AI** — Preview error detection and Ask AI no longer interrupt an in-progress run
- **Prompt mentions** — Mentions in the prompt input work again
- **Multi-conversation projects** — Auto-fix and related messages land in the conversation you have open
- **Docs panel** — PDF and video open correctly in the project docs tab
- **Design system editing** — Builder no longer loops when updating the design system document
- **File handling** — More reliable folders, binaries, and moves between docs/code
- **Mobile chat** — Layout fixes for chat/preview split and related mobile UI
- **Custom domains** — Primary domain and `www` resolution behave correctly
- **Plan downgrade** — Cancelling or returning to Free completes and stops billing as expected
- **Published site updates** — You can update a published site even if another project is at its plan limit

### Removed

- **Claude Fable 5** — Model and promotional banner removed from the picker

## v1.0.0 — May 2026

The first major release of **native.builder** — your software factory.

### Build

- **Specialized agents** — Product Architect, Builder agent, Task Planner, and Feedback agent
- **Chat context menu** — Tag agents, files, and tasks in prompts
- **Parallel agents** — Multiple agents coordinate without overwriting each other's work
- **Visual editor** — Click elements in preview and send edits to chat
- **Code editor** — TypeScript autocomplete, go-to-definition, and import completion in Monaco
- **Auto-fix** — Runtime errors in preview can trigger automatic repair
- **File upload in chat** — Attach files to your prompts
- **Model picker** — Choose from expanded model catalog; bring your own API keys (BYOK)
- **Partial file edits** — Agents send smaller diffs for faster, cheaper updates

### Documents

- **Docs tab** — Write and edit Markdown documents alongside your code with a rich editor
- **Volumes** — Separate code and documentation in organized volumes
- **File history** — View and restore previous versions of files
- **Binary uploads** — Images, PDFs, and media in your project

### Ship

- **Publish** — Deploy to a live URL on `*.nativelyai.app`
- **Custom domains** — Connect your own domain with DNS verification
- **Subdomain rename** — Change your platform subdomain; old URLs redirect for one year
- **Version history** — Snapshot and revert project versions with screenshot previews
- **Responsive preview** — Test mobile, tablet, and desktop layouts; open preview in a new tab

### Collaborate

- **Workspaces** — Invite teammates with Owner, Admin, Member, and Viewer roles
- **Shared credits** — One credit pool per workspace

### Marketplace

- **Component library** — Browse featured and popular components
- **Categories** — Filter marketplace by category
- **Store** — Discover and install templates

### Plans

- **Subscriptions and credits** — Free, Builder, Pro, Business, and Scale plans with monthly credits
- **Plan enforcement** — Project limits, custom domains, and premium models gated by plan
