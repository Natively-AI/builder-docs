## v1.3.0 — July 2026

### New

- **Command execution in sandbox** — The Builder can now run shell commands directly inside the sandbox while building your app, enabling installs, build steps, and script execution without leaving the chat flow.
- **Library documentation search** — Builder can look up third-party package and library documentation in real time, so it generates more accurate code using the APIs and patterns that packages actually expose.
- **Smarter preview refresh controls** — Preview and sandbox controls are now split: you can refresh the live preview independently without restarting the whole sandbox, which is faster and less disruptive.
- **Redesigned onboarding** — New users get a more guided experience with a cleaner onboarding flow, contextual suggested prompts in the chat composer, and timely nudges when a workspace is ready for an upgrade.

### Improved

- **Free-tier credit** — The Relay free credit allowance for new workspaces is now $2.50 USD, giving new users more room to explore before upgrading.
- **Credit billing accuracy** — Credits are now charged at per-cent precision rather than rounding to the nearest whole credit, reducing overbilling on short or fast completions.
- **Document upload limits** — Cleaner, consistent enforcement of file upload size limits across code and docs tabs.
- **Analytics depth** — Acquisition, conversion, churn, and funnel tracking expanded; attribution, login, and checkout context captured more consistently.

### Fixed

- **Billing: free-plan rate** — Free-plan users' ledger credits are now debited at the correct default rate.
- **Billing: Kimi credit drain** — Kimi model responses are now capped on output tokens to prevent unexpectedly large credit charges on long completions.
- **Sandbox stability** — The sandbox no longer stops when you scroll or click inside the live preview while a build is running.
- **Fireworks BYOK** — Resolved errors that could cause Fireworks AI completions to fail when using a bring-your-own-key connection.
- **GitHub sync button** — The Sync button on both desktop and mobile now opens the GitHub integration settings panel directly when GitHub is not connected.
- **Suggest action flow** — Agent suggestion prompts no longer lose their conversation context when cycling through options.
- **File extension change** — Uploading a file over an existing one with a different extension now asks for confirmation first, preventing accidental overwrites.
- **Tool call error details** — Raw error payloads from tool calls are no longer surfaced in the chat UI, reducing noise during normal build flows.
- **Beta banner** — The outdated "We are in beta" label has been removed from the beta indicator.

## v1.2.0 — July 2026

### New

- **Smarter long conversations** — The Builder stays on track in longer chats by recalling the most relevant earlier messages and decisions, not just the latest turns.
- **Cross-session memory** — Important project facts and decisions carry over when you return to a project, so you spend less time re-explaining context.
- **Docker app runtime** — Build apps with any stack, not just Vite/React presets. All project files are editable, including frontend environment configs. Existing projects migrate automatically.
- **Data connectors** — Connect Google Drive and Dropbox in workspace settings and use those external files as data sources inside the Builder workflow.
- **Faster live preview** — Preview loads immediately with less white flash while your app starts in the sandbox.
- **Image paste in chat** — Paste PNG or JPEG images directly into the chat composer with Cmd+V or Ctrl+V; they appear as attachment chips before you send.
- **Multi-file upload** — Select several files at once when attaching to a chat message.
- **Multiple-choice agent questions** — When the agent needs your input, it can present click-to-choose options instead of forcing every clarification into freeform text.
- **Browser completion notifications** — You can get a browser notification when a long-running build or chat finishes while you are in another tab.
- **Richer generated apps** — The Builder now uses stronger domain-specific guidance for accessibility, navigation, performance, data visualization, motion, and visual polish.
- **Smarter agent default** — Reopening an in-progress project starts with the Builder agent; new projects still begin with Product Architect.

### Improved

- **Billing emails** — Receipt, payment-failed, and cancellation emails now use branded SendGrid templates.
- **Builder docs awareness** — Builder and Product Architect can consult the official docs when reasoning about platform capabilities, which reduces guesswork in guided flows.
- **GitHub sync** — If GitHub is not connected, Sync shows a clear message and opens Integrations settings instead of a confusing OAuth popup.
- **Model availability** — Natively Max is available in the picker, Kimi is removed, and model limits are more accurate for several supported models.
- **Attachment privacy** — Uploaded filenames are no longer shown on attachment chips in the composer.
- **Upload errors** — When a file upload fails, the toast shows the specific reason from the server instead of a generic message.
- **Toasts** — All notification toasts now have a close button so you can dismiss them immediately.

### Fixed

- **Failed message retry** — If a chat message fails to send, your prompt text is restored to the composer so you can retry without retyping.
- **Auto-fix and Ask AI** — Auto-fix correctly detects preview errors again, Ask AI no longer interrupts a run that is already in progress, and the agent no longer gets stuck in a loading state after file edits when the connection reconnects.
- **Prompt mentions** — Mentions in the prompt input work again.
- **Multi-conversation projects** — Auto-fix, Send to AI, and manual file-save messages now appear in whichever conversation you have open, not always the main thread.
- **Docs panel** — PDF and video files open correctly in the project docs tab.
- **Design system editing** — The Builder no longer gets stuck in a loop when updating your app's design system document.
- **File handling** — Builder is more reliable when working with folders, binary assets, and moving files between docs/code locations.
- **Mobile chat** — Several layout and visibility fixes make chat easier to use on phones, including the preview route panel and chat/preview split.
- **Custom domains** — Setting a domain as primary works reliably; visiting a `www.` subdomain of your app resolves correctly when the bare domain is registered.
- **Plan downgrade** — Downgrading or cancelling to the free plan now completes correctly and stops billing as expected.
- **Deployment limit modal** — The upgrade prompt no longer stretches awkwardly on large screens.
- **Published site updates** — You can update a published site even when another project is currently at its plan limit.
- **Project list** — Sidebar scroll works correctly on the My Projects page.
- **Command palette** — Spotlight closes properly when dismissed.
- **Integration errors** — Clearer wording when an integration is not set up.

### Removed

- **Claude Fable 5** — The Fable 5 model and its promotional banner have been removed from the model picker.

## v1.0.0 — May 2026

The first major release of **Native.Builder** — your software factory.

### Build

- **Specialized agents** — Product Architect, Builder agent, Task Planner, and Feedback agent
- **Chat context menu** — Tag agents, files, and tasks in prompts
- **Parallel agents** — Multiple agents coordinate without overwriting each other's work
- **Visual editor** — Click elements in preview and send edits to chat
- **Code editor** — TypeScript autocomplete, go-to-definition, and import completion in Monaco
- **Auto-fix** — Runtime errors in preview can trigger automatic repair
- **File upload in chat** — Attach files to your prompts
- **Model picker** — Choose from expanded model catalog; bring your own API keys (BYOK)
- **Partial file edits** — Agents send smaller diffs for faster, cheaper updates

### Documents

- **Docs tab** — Write and edit Markdown documents alongside your code with a rich editor
- **Volumes** — Separate code and documentation in organized volumes
- **File history** — View and restore previous versions of files
- **Binary uploads** — Images, PDFs, and media in your project

### Ship

- **Publish** — Deploy to a live URL on `*.nativelyai.app`
- **Custom domains** — Connect your own domain with DNS verification
- **Subdomain rename** — Change your platform subdomain; old URLs redirect for one year
- **Version history** — Snapshot and revert project versions with screenshot previews
- **Responsive preview** — Test mobile, tablet, and desktop layouts; open preview in a new tab

### Collaborate

- **Workspaces** — Invite teammates with Owner, Admin, Member, and Viewer roles
- **Shared credits** — One credit pool per workspace

### Marketplace

- **Component library** — Browse featured and popular components
- **Categories** — Filter marketplace by category
- **Store** — Discover and install templates

### Plans

- **Subscriptions and credits** — Free, Builder, Pro, Business, and Scale plans with monthly credits
- **Plan enforcement** — Project limits, custom domains, and premium models gated by plan
