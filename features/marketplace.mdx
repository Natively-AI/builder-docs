The **Store** is where **native.builder** templates and components live. Open it from **Store** in the sidebar, or go directly to `/marketplace`.

## Templates vs. components

The Store covers two different things, and it's worth knowing which one you want before you browse:

| | Template | Component |
| --- | --- | --- |
| **What it is** | A full starting point for a new project | One piece you add into a project you're already building |
| **When you use it** | Starting something new, instead of a blank prompt | Partway through building, when you need a specific piece (for example, a pricing table or a file upload widget) |
| **What happens when you use it** | Opens as a new project, ready to iterate on in chat | Gets added into your current project's code |

## Browse and use a template

<Steps>
  <Step title="Open the Store">
    Click **Store** in the sidebar.
  </Step>
  <Step title="Browse or search">
    Look through available templates, or use **Favourites** to come back to ones you've saved.
  </Step>
  <Step title="Start a project from it">
    Pick a template to open it as a new project. It builds from the template's starting point — keep directing the **Builder agent** in chat from there, the same as any other project.
  </Step>
</Steps>

## Install a component into an existing project

<Steps>
  <Step title="Open the project you're working on">
    Open the project you want to add a component to.
  </Step>
  <Step title="Open the Store">
    Click **Store** in the sidebar.
  </Step>
  <Step title="Find the component">
    Browse or search for the component you want.
  </Step>
  <Step title="Add it to your project">
    Install it into your current project. It's added into your project's code — from there, prompt the agent in chat to wire it up or adjust it.
  </Step>
</Steps>

<Note>
  Not every template or component is available on every plan — availability depends on your plan.
</Note>

## Favourites

Save templates or components you like to your **Favourites** view so you can find them again without re-browsing the whole Store.
