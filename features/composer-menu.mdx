The chat composer has a **+** button that opens a menu of things you can add to your next message, beyond typing plain text.

## Open the menu

Click the **+** button at the start of the composer (its tooltip reads "Add attachments, mention agents, tasks, or files"). It opens a menu with four rows:

| Row | What it does |
| --- | --- |
| **Mention agent** | Bring a specific agent into the conversation — for example, switching to the **Product Architect** to plan before you switch to the **Builder agent** to implement. See the agent roster in [Prompting best practices](/features/prompting#assign-the-right-agent). |
| **Files** | Attach a file to your message from your computer, the same as pasting or dragging one into the composer. See [Attach images and files](/features/prompting#attach-images-and-files). |
| **Task** | Insert a reference to a task from your project's task board, so the agent has that task's context for the message you're sending. |
| **Import an existing project** | Bring an existing project in as context, instead of starting from a blank chat. |

## When to use it vs. just typing

For plain instructions, typing in the composer is enough — you don't need the **+** menu at all. Reach for it when you want to attach something (a file), reference something specific (a task), route the message to a particular agent, or pull in another project as context, rather than describing all of that in words.
